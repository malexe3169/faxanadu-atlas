# Custom builds, one folder per request

*[Version française](README.fr.md)*

Every build somebody asked for, as it was built. Ask for your own on
[the request page](https://malexe3169.github.io/faxanadu-atlas/custom-build/).

Each folder holds IPS and BPS patches for the versions of the game that were
asked for, and a README in English and French listing the hacks. Apply a patch
to a clean dump of the same version.

**A build is a snapshot.** It is what it was on the day, against the hack
compatibility version in its row, and it is not rebuilt when a hack changes
later. Ask again for a fresh one.
