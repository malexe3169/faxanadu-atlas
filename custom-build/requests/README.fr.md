# Builds sur mesure, un dossier par demande

*[English version](README.md)*

Chaque build demandé, tel qu'il a été bâti. Demandez le vôtre sur
[la page de demande](https://malexe3169.github.io/faxanadu-atlas/custom-build/).

Chaque dossier contient les patches IPS et BPS pour les versions du jeu
demandées, et un README en français et en anglais qui liste les hacks.
Appliquez un patch sur une copie propre de la même version.

**Un build est un instantané.** Il est ce qu'il était ce jour-là, avec la
version de compatibilité indiquée dans sa ligne, et il n'est pas rebâti quand
un hack change plus tard. Redemandez-en un neuf.
